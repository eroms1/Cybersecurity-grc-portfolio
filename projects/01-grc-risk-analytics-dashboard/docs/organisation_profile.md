# Northstar Financial Group

## Organisation Overview

Northstar Financial Group is a fictional European financial services organisation created for this cyber risk management and GRC engineering portfolio project.

The organisation operates across:

- Ireland
- United Kingdom
- Belgium
- Germany

Approximate workforce: 2,500 employees.

## Technology Environment

Key technologies include:

- Microsoft Azure
- Microsoft 365
- Microsoft Entra ID
- Microsoft Sentinel
- Microsoft Defender for Endpoint
- Rapid7
- Salesforce
- GitHub
